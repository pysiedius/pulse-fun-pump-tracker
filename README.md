# Pulse.fun — Solana memecoin tracker

Local Pump.fun price board + copy-trade console.

## Run
```bash
python3 server.py
```
Open http://127.0.0.1:8765

## Grok Build
grokbuild.com is a parked domain. Official Grok Build is [grok.com Build mode](https://grok.com/?mode=build) or the [Grok Build CLI](https://grok.build/).

Open this repo there:
https://github.com/pysiedius/pulse-fun-pump-tracker

## What it does
- Live coin list from pump.fun (price, MC, curve %, live/graduated)
- Trench dev wallets preloaded for copy tracking
- Phantom connect (no private keys stored)
- Copy opens pump.fun + local signal feed
